# guideme

Type-safe inline judgments from TypeSafe Jev, for Python: a yes/no is an `if`, a choice is an
exhaustive `match`, a score is a comparison.

Work in progress, not yet on PyPI. [`AGENTS.md`](AGENTS.md) is the working rulebook and
[`CONTRIBUTING.md`](CONTRIBUTING.md) is where to start. The cross-SDK contract is published by
[guideme-rust](https://github.com/pedro-pscunha/guideme-rust) and vendored here under `spec/`.
